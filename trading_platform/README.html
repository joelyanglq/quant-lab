? What — 这是什么

trading_platform 是一个 模块化、事件驱动 的美股量化交易框架。 它把从信号生成到真实下单的全链路，拆解为可独立测试和替换的纯函数层。

一份代码，四种运行

同一个 Alpha 子类、同一个 CompositeStrategy， 无修改即可在 backtest / shadow / paper / live 四种模式下运行。 运行时差异被 ExecutionHandler 和 DataFeed 封装。

四类策略，统一接口
  • 单票择时 (Timing)
  • 截面多因子 (Cross-Section)
  • 配对统计套利 (Pairs/Stat-Arb)
  • 板块/风格轮动 (Rotation)

全部实现 forecast(dt) → dict[sym, float]，引擎对策略类型透明。

Carver 全链路实现

严格遵循 Robert Carver 的 Forecast → Combine → Size 三层模型： forecast 标准化 (Ch7)、handcrafted 权重 (Ch4)、vol-target (Ch9)、 half-Kelly (Ch9)、drawdown scaling (Ch10)、SR plausibility flag (Ch2)。

! Why — 设计动机

解决量化策略从研究到实盘的"最后一公里"问题。

研究 ≠ 生产

传统回测框架的策略代码无法直接在实盘运行。 本框架通过统一事件模型 (Bar, OrderEvent, FillEvent) 和抽象执行层，让策略代码在回测和实盘之间零修改切换。

Carver 而非 Zipline

区别于 portfolio-level weight 方法，Carver 架构把预测 (forecast)、合并 (combine)、 定量 (size) 分成三个独立纯函数，每层可单独测试、替换、调参。 这让多策略组合天然成为"加一个 Alpha + 调整 Combiner 权重"。

渐进上线

Shadow (看不下单) → Paper (IBKR 模拟盘) → Live (真实资金)。 每一步用同一份代码和 Kill-Switch 保护。 小资金先跑，验证滑点/对账后再加仓。

λ 三层乘性架构 (Carver Ch5)

每一层是独立纯函数 — 可单独测试、可单独替换。

Sizing 公式

position[i] = (forecast[i] / 10) # 标准化 × (target_vol_per_inst / σ[i]) # vol target × (capital × weight[i] / price[i]) # 转手数 × half_kelly_factor # 0.5 × SR / σ, clipped [0.3, 1.0] × drawdown_scaler # 1.0 → 0.5 → 0 at 5%/10%/20% DD

⇒ 数据流 & 核心管线

从市场数据到订单执行的完整事件驱动路径。

事件序列 (每根 Bar)

StepComponentAction
1DataFeedEmit Bar (from Parquet or IBKR real-time)
2EngineSet clock → update Portfolio.update_market() → call Execution.process_bar() (fill pending orders)
3CompositeStrategyReceive on_bar(), trigger _rebalance(dt) if frequency matches
4Alpha[]Each alpha computes forecast(dt, ctx) → {sym: float}
5CombinerMerge all forecast dicts (weighted/layered/handcrafted)
6RiskSizerCombined forecast × vol-target × Kelly × DD-scale → target shares
7CompositeStrategyDiff: target − current → OrderEvent per symbol delta
8ExecutionHandlerSubmit order (queue / shadow-log / IBKR-place)
9PortfolioOn FillEvent: update positions, cash, equity curve

♦ 四类策略原型

全部实现 Alpha 接口，引擎完全透明。

Archetype Module Signals Trigger Universe
Single-Name Timing archetypes/single_name_timing.py HHT, QRS, MA Cross, RSI, Momentum EOD / Intraday User-specified symbols
Cross-Section Multi-Factor archetypes/cross_section.py Momentum 12-1, Short Reversal, Low Vol + custom factors Weekly / Monthly S&P 500 / NDX 100
Pairs / Stat-Arb archetypes/pairs.py Log-spread z-score (Engle-Granger cointegration) 30min / EOD Pre-scanned cointegrated pairs
Sector Rotation archetypes/rotation.py 12-1 Momentum, cross-sectional z-score Monthly / Weekly 11 Sector ETFs (XLK, XLF, ...)

Cross-Section 因子流程

Universe (SP500 + NDX100) → Factor panels (momentum, reversal, low_vol, ...) → Cross-sectional z-score (optional sector-neutral) → Expanding-window IC correlation → Handcrafted factor weights (Carver Ch4) → Composite forecast per symbol → ScalingMixin → [-20, +20]

Pairs Entry/Exit 规则

spread = log(P_A) − β × log(P_B) z_score = (spread − rolling_mean) / rolling_std Entry: |z| ≥ entry_z (default 2.0) → short spread if z > 0, long if z < 0 Exit: |z| < exit_z (default 0.5) Stop: |z| > stop_z (default 4.0) → force close

⊗ 风控体系 (Kill-Switch)

kill_switch.json 持久化状态。任何触发 → 取消全部挂单 + 拒绝新订单 + 报警。
重启不自动重置 — 必须显式 KillSwitch().reset(operator_confirm=True)。

TriggerDefaultBehavior
Leverage breach > 1.0 (live: 0.5) Immediate trip — cancel all orders
Daily P&L loss > 2% NetLiq (live: 1%) Immediate trip
Single strategy 7-day loss > 5% allocation Pause that strategy only
IBKR disconnect > 5 minutes Auto trip
Price anomaly Bar-to-bar > 50% Pause that symbol (no global trip)
Position reconciliation mismatch > 1 share or $100 Immediate trip

Additional Safety Layers

Reconciliation

Every 60 seconds, compare local Portfolio positions against IBKR broker positions. Mismatch beyond tolerance triggers kill-switch.

Order Audit Log

Append-only JSONL log of all orders and fills. Immutable record for post-mortem and compliance.

Slippage Monitor

Track realized slippage vs expected fill regime. Alert if systematic adverse slippage detected.

μ 回测分析 (Analytics)

基于 Carver 的 performance evaluation 框架，含 plausibility flags。

Core Metrics
  • Annual Return / Annual Volatility
  • Sharpe Ratio + Confidence Interval (t-test & bootstrap)
  • Max Drawdown + Calmar Ratio
  • Skewness
  • Rolling Sharpe (252-day window)
Plausibility Flags (Carver Ch2)
  • SR > 0.5 for single-instrument → WARNING
  • SR > 1.0 for portfolio strategy → WARNING
  • Negative skew detected → WARNING
  • Flags help detect overfitting / look-ahead bias

>_ 命令行用法

Backtest

# 单票择时 (HHT)
python -m trading_platform.runtime.backtest \
    --start 2020-01-01 --end 2024-12-31 \
    --strategy timing --symbols AAPL,MSFT,NVDA --rule HHT

# 多因子截面 (周频, sector-neutral)
python -m trading_platform.runtime.backtest \
    --start 2020-01-01 --end 2024-12-31 \
    --strategy cross_section --rebalance W-FRI

# 板块轮动 (月频)
python -m trading_platform.runtime.backtest \
    --start 2018-01-01 --end 2024-12-31 \
    --strategy rotation --rebalance M

# 配对交易 (先扫描协整对, 再回测)
python -m trading_platform.runtime.pairs_scanner \
    --start 2020-01-01 --end 2024-01-01 --p 0.05
python -m trading_platform.runtime.backtest \
    --start 2024-01-01 --end 2025-12-31 \
    --strategy pairs

Shadow → Paper → Live (渐进上线)

# Step 1: Shadow — 连 IBKR 实时数据, 不发单 (≥1 周)
python -m trading_platform.runtime.live --mode shadow \
    --strategy timing --symbols AAPL --rule HHT --bar-size '5 mins'

# Step 2: Paper — IBKR 模拟盘下单 (≥2 周)
python -m trading_platform.runtime.live --mode paper --port 7497 \
    --strategy timing --symbols AAPL --rule HHT --bar-size '5 mins'

# Step 3: Live — 真实资金, 需显式确认
python -m trading_platform.runtime.live --mode live --port 7496 \
    --strategy timing --symbols AAPL --rule HHT \
    --initial-capital 5000 --max-leverage 0.5 --max-daily-loss 0.01 \
    --i-understand-this-uses-real-money

+ 扩展策略

继承 Alpha + ScalingMixin，实现 forecast() 即可。

from trading_platform.strategy import Alpha, ScalingMixin

class MyCustomAlpha(Alpha, ScalingMixin):
    trigger_freq = Frequency.EOD

    def __init__(self):
        super().__init__()
        self._init_scaling(window=252)

    def forecast(self, dt, ctx):
        prices = ctx.as_of(dt, "price_1d", lookback=60)
        raw = {}
        for sym in self.universe(dt, ctx):
            raw[sym] = your_signal_logic(prices[sym])
        return self._scale_and_cap(raw)  # → [-20, +20]
