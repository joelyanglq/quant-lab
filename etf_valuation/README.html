ETF Valuation System

Bottom-up ETF 估值监控 — FMP ETF Holdings × FMP 个股 Ratios → 加权聚合 → 历史分位 → 择时信号 → 时序图

核心思路

美股 ETF 本身没有 P/E、P/B 等基本面数据。本系统通过 FMP ETF Holdings API 获取每只 ETF 的实时持仓权重（每日更新），结合 FMP 全市场个股 TTM ratios， 用加权调和/算术平均聚合出 ETF 级别的 7 大估值指标，再追踪历史分位数，生成买卖信号和时序轨迹图。

7 大估值指标

#MetricDirectionAggregationFMP Field适用场景
1P/E TTM ↑ expensive Harmonic priceToEarningsRatioTTM 盈利稳定行业
2P/B LF ↑ expensive Harmonic priceToBookRatioTTM 重资产 / 金融 / 周期
3P/S TTM ↑ expensive Harmonic priceToSalesRatioTTM 高成长 / 亏损行业
4Div Yield ↑ cheap Arithmetic dividendYieldTTM 收益型 ETF
5ERP ↑ cheap Arithmetic 1/PE − 10Y Treasury 股债性价比
6FCF Yield ↑ cheap Arithmetic 1/priceToFreeCashFlowRatioTTM 成熟科技 / 工业
7EV/EBITDA ↑ expensive Harmonic enterpriseValueMultipleTTM 杠杆差异大的行业

Harmonic Mean：ratio 类指标的行业标准聚合方式，避免极端值（负PE）扭曲结果。 Arithmetic Mean：yield 类指标直接加权求和。负值成分股被剔除，覆盖率 < 70% 标记低可信度。

信号系统

Percentile标签信号操作建议
0 – 10%极度低估STRONG_BUY重仓买入
10 – 25%低估BUY加仓
25 – 40%偏低LEAN_BUY小幅加仓
40 – 60%合理HOLD持有观望
60 – 75%偏高LEAN_SELL小幅减仓
75 – 90%高估SELL减仓
90 – 100%极度高估STRONG_SELL清仓

复合评分: composite = primary_pct × 0.7 + secondary_pct × 0.3， direction 自动标准化为 "higher = more expensive"。

模块架构

fetcher.py — FMP Holdings + Ratios Bulk

  • FMPHoldingsFetcher — /stable/etf/holdings 实时持仓权重
  • 直接返回 ticker + weight（无需 CUSIP 映射），每日更新
  • RatiosBulkFetcher — /ratios-ttm-bulk CSV, 71K+ stocks
  • 年分片存储: YYYY_ratios_ttm.parquet
  • YFinanceValidator — 交叉校验 ETF 级别估值

nport.py — SEC N-PORT 下载 + 解析 (历史重建用)

  • ETF_CIK_MAP — 38 ETFs 的 CIK + series_id 注册表
  • NPortDownloader — 下载 XML、解析持仓 (cusip, weight, value, shares)
  • 仅用于 history.py 历史重建，日常 pipeline 不再调用
  • Multi-series trusts: 通过 seriesId 过滤

cusip_map.py — CUSIP → Ticker 映射 (历史重建用)

  • CusipMapper — 三种映射策略: OpenFIGI / FMP Profile / Name Match
  • 仅用于 N-PORT 历史重建路径
  • 缓存: cusip_to_ticker.parquet (1035+ mappings)
  • 日常 pipeline 不需要（FMP holdings 直接提供 ticker）

metrics.py — 加权聚合计算

  • weighted_harmonic_mean — Ratio 类 (PE/PB/PS/EV), 行业标准
  • weighted_arithmetic_mean — Yield 类 (DivYld/FCF)
  • aggregate_etf_metrics — Holdings × Ratios JOIN → ETF 估值
  • ERP 特殊计算: 1/PE − 10Y_Treasury

percentile.py — 历史分位数

  • rolling_percentile — 5 年滚动窗口
  • expanding_percentile — 短历史自适应
  • 最少 60 个观测值才开始计算

scoring.py — 信号评分

  • 7 级信号: STRONG_BUY → STRONG_SELL
  • composite_score — 主指标 0.7 + 副指标 0.3
  • Direction 自动标准化 (higher_cheap 翻转)

report_charts.py — 时序轨迹图

  • generate_timeseries_charts() — per-tier 分组图表生成
  • 每个 ETF: primary + secondary 指标双列面板
  • Mean/±1σ band, P10/P90 dotted lines, COVID shading
  • 当前值 dot 颜色 = signal color, info box 含 percentile + signal
  • 输出: ts_broad_, ts_sectors_, ts_themes_, ts_spy_deep_

SEC N-PORT 技术细节

XML 结构

每个 <invstOrSec> 节点包含:

  • cusip — 9 位证券标识符
  • pctVal — 占基金净值百分比 (权重)
  • valUSD — 美元市值
  • balance — 持股数量
  • identifiers/isin — ISIN (可选)

Multi-Series Trust 处理

大型信托 (如 iShares = 1460+ filings) 同一 CIK 下包含多只 ETF。 通过 XML 中的 <seriesId> 字段过滤匹配目标 ETF。

  • CIK filing list 缓存 — 避免重复 HTTP 请求
  • max_scan=500 — 限制扫描深度
  • max_quarters=2 — 只取最新 2 个季度
